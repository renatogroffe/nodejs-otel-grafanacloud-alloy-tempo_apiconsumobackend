# nodejs-otel-grafanacloud-alloy-tempo_apiconsumobackend
Exemplo de API REST criada com o Node.js e utilizando OpenTelemetry + Grafana Cloud + Alloy para tracing distribuído e consumindo 2 endpoints de uma API REST de contagem de acessos. Prova de conceito para uso com ambientes empregados em testes de observabilidade.

API REST consumida por este projeto: **https://github.com/renatogroffe/aspnetcore10-otel-grafanacloud-alloy-tempo-loki-postgres-mysql-testcontainers_contagemacessos**
